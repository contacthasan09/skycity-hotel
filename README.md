# Sky City Hotel Dhaka — React Site

Light, multi-page recreation of [skycityhotelbd.com](https://www.skycityhotelbd.com) design system.

## Routes

| Path | Page |
|------|------|
| `/` | Home |
| `/about` | About Us |
| `/rooms` | Rooms & Suites |
| `/dining` | Restaurants & Dining |
| `/room-service` | In-Room Dining |
| `/wellness` | Spa & Wellness |
| `/meetings` | Meetings & Events |
| `/offers` | Offers |
| `/gallery` | Gallery |
| `/location` | Location |
| `/contact` | Contact |

## Run

```bash
cd skycity-react
npm install
npm run dev
```

## Design tokens

- Teal brand: `#00586b`, cyan action `#069ec0` / `#51d6f3`
- Gold CTA: `#c9973d`
- Text: `#2a2a2a`
- Fonts: Open Sans, Signika
- Buttons: gold Book Now, cyan form submit, pill secondary (24px radius)
